## 2\. Descripción y objetivo

**Problema:**  
La coordinación académica necesita organizar y procesar información de talleres estudiantiles. Se requiere registrar las cantidades de inscritos, ordenar resultados, realizar consultas puntuales y representar la distribución de estudiantes por aulas y bloques horarios. En esta primera etapa se trabajará únicamente con estructuras lineales estáticas.

**Objetivo:**  
Plantear una solución utilizando estructuras lineales estáticas para organizar, procesar y consultar la información de inscritos y de ocupación de aulas y horarios, aplicando vectores y matrices.

**Solución desarrollada:**  
La solución se plantea inicialmente mediante el análisis y selección de estructuras de datos estáticas, justificando el uso de vectores y matrices para el caso. Luego se aplican operaciones sobre un vector para representar, buscar, insertar y ordenar datos de inscritos, y se utiliza una matriz para representar y procesar la ocupación de aulas y horarios. Finalmente, se analizan matrices especiales para reconocer situaciones en las que una matriz poco densa puede ser más conveniente.

## 7\. Conclusiones

- Conclusión 1: Las estructuras lineales estáticas (vectores y matrices) son fundamentales para almacenar y organizar datos de manera eficiente cuando el tamaño es conocido. En el caso del sistema académico, permiten acceso rápido por índice y facilitan operaciones comunes como búsqueda, inserción y ordenamiento.   
    
- Conclusión 2: El ordenamiento burbuja, aunque simple de implementar, tiene una complejidad de O(n²), lo que lo hace ineficiente para grandes volúmenes de datos. Esto evidencia la importancia de seleccionar algoritmos según el contexto y el tamaño de los datos.   
    
- Conclusión 3: La solución desarrollada demuestra cómo aplicar conceptos teóricos de estructuras de datos en problemas reales. El sistema puede registrar inscritos, ordenarlos, consultar ocupación de aulas y optimizar el uso de recursos.
